# Immediate indicator-sharing baseline — frozen specification

This is a separate research comparator mandated by section 6.5 of the roadmap and implementation plan. It is not a new component of CredBlock-FL. No change is made to either professor diagram, original local inference, model weights, binary64 thresholds, split assignments, eligibility masks, primary fixed-grid unit or 1% target.

The versioned configuration and preregistration freeze one policy before new comparison outcomes. There is no policy search, TEST access or hidden-label join. Ten-minute attribution and TTL are transparent baseline choices aligned with the accepted recent-feature clock, not measured optima.

At a complete local timestamp, the original detector updates its persistent seven-day graph and scores the same User targets as before. Only actual original GraphSAGE ALERT rows can seed indicators. For each such User, all distinct exact IP strings in the local recent event queue `(t-600 seconds,t]` are eligible, regardless of authentication success. User membership is never used across organizations. IPs have status `suspicious_unverified`; association with an alerted User does not establish maliciousness. A local alert with no recent evidence issues nothing.

At most one live episode exists per issuer and exact IP. Repeated local alert/IP candidates are suppressed while live, without renewal. A fresh original local alert at or after expiry may create another episode. Different issuers remain separate provenance sources. Indicators expire at `issue+600 seconds`, exclusive; no ground-truth revocation or manual correction is implemented.

The network receives only eight fields: indicator ID, exact IP, issuer, issue time, availability time, expiry time, policy version and unverified status. The opaque indicator ID depends on policy/issuer/IP/issue time, never on local User or alert IDs. Private provenance maps it to the source alert locally. No raw log, User ID, synthetic credential, complete graph, risk score or feature is broadcast.

At global timestamp `t`, expire due records first. Then all local commands at `t` finish independent graph update/scoring and attribution. Sort all resulting envelopes and immediately deliver each to all four other recipients at availability `t`. Only after this publication barrier are local-plus-indicator decisions finalized for current authentication at `t`. This permits equal-time use without depending on organization iteration order. Earlier finalized decisions remain immutable. Receipt does not retrospectively match older authentication activity. Indicator-assisted decisions cannot create further indicators.

On each original local scored User row, the paired decision is `local_alert OR current authentication from a received live IP indicator`. Both detector decisions are retained. Heartbeat rows without current authentication receive no indicator assistance. Current event Users without original local scores are logged separately with `local_status=NOT_SCORED`, and do not become local no-alerts in the paired denominator. New-IP rotation receives no match until that address is independently indicated. Shared benign IPs and false local alerts can propagate extra suspicion under the same rule. If no local organization alerts, no indicator exists.

Five fresh full-hour actual local inference runs must exactly reproduce accepted Subphase 6 canonical scores/alerts and graph hashes. Their original model/threshold registry, source manifests and configurations are verified. Sharing has no feedback into local graphs, scoring, targeting or models. Therefore the global comparison can interleave these immutable causal local journals: each local adapter restores its own original warm-up checkpoint, updates the same accepted graph at every command, attributes from current local evidence, and receives only IP envelopes. It does not recompute unchanged GNN scores during the sharing replay. The full global replay is repeated in reverse organization order to test barrier reproducibility. Original accepted journals remain untouched.

All source observations through the exclusive hour end are retained, with the original final-microsecond flush. After observations end, an expiry-only drain demonstrates all indicators stop being live; it does not introduce new model/event decisions. Public network logs record creation/broadcast/expiry. Organization-local logs record receipt/utilization/expiry; private logs preserve paired decisions and source-alert provenance.

Zero propagation delay is a simulated optimistic assumption, not real networking latency. Fresh local GNN resource/latency measurements and sharing-adapter CPU/wall/RSS timings are separate. Per-adapter timing includes local journal reads, graph replay, attribution, receipt matching and buffered decision writes, but excludes original GNN materialization and final close/hash costs. No production security, network transport or latency guarantee is established.

Operational User-score pairs are not the primary fixed-grid eligible User-time evaluation. No operational FPR/recall or campaign detection-time claim is made without authorized offline labels. The calibrated 1% grid FPR does not transfer to the OR rule or arbitrary event scoring. This subphase is one complete predeclared VAL hour per organization, not all families/seeds, final TEST, campaign detectability, federation, DP, robust aggregation or Fabric. Subphase 8 requires explicit user acceptance of Subphase 7.
